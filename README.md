# Payment

一份脱敏后的移动支付客户端逆向观测记录归档。

本仓库只收录一篇公开版长文：[`某移动支付客户端逆向观测记录.md`](./某移动支付客户端逆向观测记录.md)。

## 内容概览

归档把两条独立主线合成一篇，另附一份静态测绘：

- **口令解密线（静态 + 补环境）**：SP 密文与口令生成器、Java 调用链、目标 so 的 ELF 测绘、IRELATIVE 表四槽区、resolver 判读、Unicorn 补环境、内存桩与 roundtrip 对照。
- **动态观测线（hook）**：后端接口族捕获、弹窗实现定位、加密封装观测、架构结论、稳定 hook 配置与死路清单、启动流程控制闭环及其迭代教训。
- **静态测绘线**：RPC 签名链还原、网关白名单与签名算法、组件面机制归类、三条线互补关系。

全文用 TOP 章节组织，含大量树状图与函数、地址、偏移、槽位、常量记录；凡原始材料标注「未验证 / 未实现 / 未读 / FAILED / 零触发 / 禁用」的，一律保留该状态，不补写结论。

## 脱敏说明

- 品牌、厂商、测试账号一律泛化，不出现具体产品名与真实号码。
- 网络端点、完整 URL、签名头与签名值全部脱敏，只保留字段结构与调用栈。
- 密钥值、证书内容、密文样例、PoC、攻击载荷与漏洞利用链均不收录；组件面部分只做机制归类与静态判据转述。
- 代码标识符中的类名、方法名、函数名与各类数字照录（含品牌词的类名做局部泛化）。

## 阅读顺序

1. 先看文首「命名与脱敏」「验证状态」两节，明确口径。
2. 第一部按 TOP0→TOP13 了解口令解密线。
3. 第二部按 TOP14→TOP21 了解动态观测线。
4. 第三部按 TOP22→TOP25 了解静态测绘与三条线互补。
5. 收尾「未竟事项」列出各处未完成项。
